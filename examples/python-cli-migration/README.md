# Python CLI 可复现迁移样例

这是一个刻意保持很小的合成 fixture，用来展示“只读审计 → 最小治理材料”的可观察变化，不代表任何真实团队的效率、质量或接受度成效。

- `before/`：只有产品代码、测试和构建元数据。
- `after/`：产品文件保持一致，只增加 AI 入口、贡献说明、协作约定、评审模板、变更提案、安全说明、文档索引和 CI。

运行：

```powershell
python scripts\compare_fixture.py --format markdown
```

输出数字来自当次扫描。`已有路径信号组` 只表示脚本检测到了约定路径，不验证文件内容质量；`待确认迁移项` 变少也不是合规评分。对比器会列出审计前后的相对路径与 SHA-256 快照，以便复核只读审计没有改写 fixture；计算哈希时读取的是这个合成案例，审计器本身仍不读取目标文件内容。
